# NEXUS Control Tower — Apple Design Concept

## Abrir el prototipo
1. Descomprime `NEXUS_Apple_Design_Concept.zip`.
2. Abre `index.html` con Safari, Chrome o Edge.
3. Pulsa **Explorar el tablero** y navega por Resumen, Misiones, Proveedores y Reportes.

No requiere instalación, servidor ni conexión a GitHub.

## Archivos
- `index.html`: maqueta interactiva responsive.
- `DESIGN-NOTES.md`: decisiones de diseño y alcance.
- `README.md`: instrucciones.

## Importante
Este es un concepto visual independiente. No modifica el repositorio, no reemplaza la web publicada y no se conecta a los datos reales. Los nombres, resultados y cifras son de demostración. Las exportaciones son ilustrativas; el botón de reporte no genera el PDF real de NEXUS.
